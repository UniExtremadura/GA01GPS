# GA01GPS - Subsonic Festival

Repositorio del grupo GA01 para la asignatura Gestión de Proyectos Software.

El proyecto consiste en la planificación de un sistema de gestión para Subsonic Festival, incluyendo usuarios, entradas, espacios, servicios, proveedores, merchandising e incidencias.

## Organización del proyecto

Para realizar la planificación hemos definido 19 historias de usuario agrupadas en 7 épicas. También hemos establecido sus prioridades, estimaciones, dependencias y responsables.

La planificación vigente se organiza en seis iteraciones semanales, agrupadas en tres releases de dos semanas.

Hemos establecido una disponibilidad de 6,25 horas semanales por integrante para desarrollar los requisitos. Esto supone una capacidad de 31,25 horas semanales entre los cinco miembros del equipo y un total de 187,5 horas durante las seis iteraciones.

Las 19 historias de usuario tienen un esfuerzo estimado de 115 horas-persona, por lo que contamos con un margen de 72,5 horas respecto a la capacidad disponible.

Las reuniones de Scrum, revisiones y demás tareas de gestión se realizan aparte y no están incluidas en las horas destinadas a los requisitos.

El coste estimado del trabajo asignado a los requisitos es de 3.795 €, calculado a partir de las horas de cada integrante y las tarifas establecidas.

## Estado del proyecto

Actualmente el proyecto se encuentra en fase de planificación. Se han definido los 19 requisitos y se ha actualizado la planificación en Excel a seis iteraciones semanales.

La planificación de ProjectLibre se está adaptando a esta nueva distribución para mantener la coherencia con el Excel y la documentación de la Wiki.
