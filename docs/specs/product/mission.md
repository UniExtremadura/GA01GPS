# Idea del producto

Subsonic Festival 2026 es una aplicación web orientada a centralizar la gestión y los servicios asociados a un festival de música.
La plataforma pretende ofrecer un entorno común que facilite tanto la experiencia de los clientes del festival como las tareas realizadas por proveedores y administradores.
El producto busca evitar que la información y los diferentes servicios relacionados con el festival se encuentren distribuidos entre distintas herramientas, proporcionando una experiencia única, organizada y accesible para sus usuarios.

# Contexto y necesidad

La organización de un festival implica la participación de diferentes tipos de usuarios y la gestión de numerosos elementos relacionados con el evento.
Cuando estos procesos se realizan mediante sistemas independientes o de forma poco centralizada pueden aparecer problemas como:

- Información fragmentada o difícil de localizar.
- Dificultad para acceder a los diferentes servicios disponibles.
- Mayor complejidad para gestionar la información del festival.
- Falta de coordinación entre los distintos participantes.
- Una experiencia poco clara para los clientes.

Subsonic Festival 2026 surge para proporcionar un punto común desde el que gestionar y utilizar los servicios relacionados con el festival.


# Los usuarios principales son:

# Cliente

Es el usuario que utiliza los servicios ofrecidos por Subsonic Festival 2026.
Necesita disponer de una plataforma clara y sencilla desde la que pueda acceder a la información y a los servicios disponibles relacionados con el festival.
La experiencia del cliente debe permitirle conocer en todo momento el resultado de las acciones realizadas y continuar de forma sencilla cuando se produzca un error recuperable.

# Proveedor

Es el usuario encargado de proporcionar determinados productos o servicios asociados al festival.
Necesita disponer de un entorno desde el que pueda gestionar la información y las operaciones que le correspondan, manteniendo una separación clara entre sus permisos y los del resto de usuarios.

# Administrador

Es el usuario responsable de supervisar y gestionar la información necesaria para el funcionamiento de la plataforma.
Necesita disponer de mecanismos que le permitan mantener de forma controlada los diferentes elementos del sistema y realizar las operaciones administrativas necesarias.

# Problema que se quiere resolver

Subsonic Festival 2026 pretende reducir la fragmentación existente en la gestión de los diferentes elementos de un festival.
El producto busca que los clientes no tengan que depender de diferentes medios para acceder a los servicios del evento y que proveedores y administradores dispongan de un entorno común desde el que realizar las operaciones correspondientes a su rol.
De esta forma, la plataforma pretende conseguir una interacción más organizada entre los diferentes participantes del festival.

# Propuesta de valor

Subsonic Festival 2026 proporciona una plataforma única para centralizar diferentes procesos y servicios relacionados con un festival de música.
Frente a una gestión distribuida entre diferentes herramientas, pretende aportar:

- Un único punto de acceso para los usuarios.
- Información organizada y comprensible.
- Separación clara de las acciones disponibles según el rol del usuario.
- Mayor control sobre las operaciones realizadas.
- Una experiencia coherente entre los diferentes servicios.
- Una interacción más sencilla entre clientes, proveedores y administradores.
- Mayor seguridad y control en la gestión de la información.

# Declaración de misión

La misión de Subsonic Festival 2026 es proporcionar una plataforma web centralizada, clara y fiable que facilite la interacción de clientes, proveedores y administradores con los diferentes servicios asociados a un festival de música, ofreciendo una experiencia organizada, segura y accesible.

# Experiencia deseada

Subsonic Festival 2026 debe proporcionar una experiencia:

- Clara: la información y las acciones disponibles deben ser fáciles de comprender.

- Centralizada: los principales servicios relacionados con el festival deben estar disponibles desde un mismo entorno.

- Consistente: las diferentes partes de la plataforma deben mantener un comportamiento y una presentación coherentes.

- Segura: cada usuario debe acceder únicamente a las operaciones correspondientes a su rol y la información debe tratarse de forma controlada.

- Transparente: el sistema debe informar al usuario del resultado de las acciones realizadas.

- Recuperable: cuando se produzca un error recuperable, el usuario debe recibir información clara sobre cómo continuar.

- Accesible: las interfaces y los principales flujos deben considerar la diversidad de capacidades de los usuarios.

- Fiable: la información y el estado mostrado por el sistema deben ser coherentes con las operaciones realizadas.

# Relación con la constitución

Esta misión establece el propósito y el valor que debe aportar Subsonic Festival 2026.
Las funcionalidades propuestas durante el proyecto deberán contribuir a esta misión y aportar valor a alguno de los usuarios definidos.
Los objetivos medibles, las métricas de éxito, el alcance, las exclusiones, los supuestos y las restricciones se definirán en `goals.md`.
Cualquier funcionalidad que no contribuya a los objetivos derivados de esta misión deberá considerarse fuera del alcance hasta que se apruebe el cambio correspondiente.
